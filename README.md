# Coursewise

Coursewise helps students organize Canvas coursework. The browser extension customizes Canvas and shows grades, deadlines, announcements, and course pictures. The web app offers calendar import, grade goals, study plans, file storage, manual flashcards, reminders, export, and deletion.

The extension is in [extension](./extension), and the web app is in [site](./site). The active `main` source contains the non-AI release. Earlier AI development is preserved on the `AI-Changes-Round-1` branch.

See each directory's README for setup and release instructions.
